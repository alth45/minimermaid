MiniMermaid

Kode Diagram
Bentuk: square round circle ellipse diamond triangle hexagon parallelogram cylinder document
Sambung: tambahkan ->node di akhir baris untuk menyambung ke node berikutnya secara otomatis.
Baris baru dalam teks: tulis \n

📖 Panduan Sintaks MiniMermaid

1. Node Dasar

Satu node ditulis per baris. Gunakan ->node di akhir untuk menyambung ke node berikutnya.

->[round]->text["Mulai"]->node
->[square]->text["Proses Data"]->node
->[triangle]->text["Selesai"]

2. Bentuk Node & Alias

Mendukung bahasa Indonesia dan Inggris.

  • square / kotak
  • round / kapsul
  • diamond / belahketupat
  • cylinder / database / db
  • document / dokumen
  • hexagon / segi enam
  • parallelogram / jajargenjang
  • circle, ellipse, triangle

3. Label Multi-baris

Gunakan \n untuk membuat baris baru di dalam label.

->[diamond]->text["Kondisi\nTerpenuhi?"]

4. Arah Horizontal

Tambahkan [horizontal] di baris paling atas.

[horizontal]
->[round]->text["Mulai"]->node
->[diamond]->text["Cek"]->node
->[square]->text["Selesai"]

5. Percabangan Datar

Gunakan [cabang] diikuti dengan sisi ->ya dan ->tidak.

[cabang]->[diamond]->text["Lulus?"]
->ya["Ya"]
->[square]->text["Sertifikat"]
->tidak["Tidak"]
->[square]->text["Ulang"]

6. Percabangan Bertingkat (Bagan)

Gunakan Indentasi (Spasi/Tab) di bawah ->ya atau ->tidak untuk membuat sub-cabang.

[cabang]->[diamond]->text["Punya Akun?"]
  ->ya["Ya"]
    [cabang]->[diamond]->text["Verifikasi?"]
      ->ya["Ya"]
        ->[round]->text["Dashboard"]
      ->tidak["Belum"]
        ->[square]->text["Kirim Email"]
  ->tidak["Tidak"]
    ->[square]->text["Daftar"]
