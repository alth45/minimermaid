MiniMermaid

Kode Diagram
Bentuk: square round circle ellipse diamond triangle hexagon parallelogram cylinder document
Sambung: ->node di akhir baris untuk menyambung ke node berikutnya.
Label panah: ganti ->node dengan -- label --> di akhir baris.
Baris baru dalam teks: tulis \n Edit node: klik node di preview untuk membuka panel properti.

📖 Panduan Sintaks MiniMermaid

1. Node Dasar

Satu node ditulis per baris. Gunakan ->node di akhir untuk menyambung ke node berikutnya. 

->[round]->text["Mulai"]->node
->[square]->text["Proses Data"]->node
->[triangle]->text["Selesai"]

2. Bentuk Node & Alias

Mendukung bahasa Indonesia dan Inggris.

  • square / kotak
  • round / kapsul
  • diamond / belahketupat
  • cylinder / database / db
  • document / dokumen
  • hexagon / segi enam
  • parallelogram / jajargenjang
  • circle, ellipse, triangle

3. Label Multi-baris

Gunakan \n untuk membuat baris baru di dalam label.

->[diamond]->text["Kondisi\nTerpenuhi?"]

4. Arah Horizontal

Tambahkan [horizontal] di baris paling atas.

[horizontal]
->[round]->text["Mulai"]->node
->[diamond]->text["Cek"]->node
->[square]->text["Selesai"]

5. Percabangan Datar

Gunakan [cabang] diikuti dengan sisi ->ya dan ->tidak.

[cabang]->[diamond]->text["Lulus?"]
->ya["Ya"]
->[square]->text["Sertifikat"]
->tidak["Tidak"]
->[square]->text["Ulang"]

6. Percabangan Bertingkat (Bagan)

Gunakan Indentasi (Spasi/Tab) di bawah ->ya atau ->tidak untuk membuat sub-cabang.

[cabang]->[diamond]->text["Punya Akun?"]
  ->ya["Ya"]
    [cabang]->[diamond]->text["Verifikasi?"]
      ->ya["Ya"]
        ->[round]->text["Dashboard"]
      ->tidak["Belum"]
        ->[square]->text["Kirim Email"]
  ->tidak["Tidak"]
    ->[square]->text["Daftar"]

7. Label pada Panah

Ganti ->node dengan -- label --> di akhir baris untuk memberi teks label pada panah yang menuju node berikutnya. 

->[round]->text["Mulai"]-- mulai -->
->[square]->text["Validasi"]-- oke -->
->[diamond]->text["Sukses?"]-- ya -->
->[triangle]->text["Selesai"]

8. Diagram ER (Entity Relationship)

Gunakan [er] di baris pertama. Deklarasikan entitas dengan entity Nama { ... }, atribut dengan prefix opsional PK / FK / PK/FK. Relasi ditulis dengan 1, N (atau M/*), atau ? (optional). 

[er]
entity User {
  PK id int
  name string
  email string
}
entity Post {
  PK id int
  FK user_id int
  title string
}
User 1 -- N Post : menulis
User 1 -- ? Profile : memiliki

9. Mindmap (Peta Pikiran)

Gunakan [mindmap] di baris pertama. Tiap baris berikutnya merepresentasikan satu node; hierarki dibentuk oleh indentasi (spasi/tab). Baris pertama = root, otomatis diletakkan di tengah dan cabang utama dibelah ke kiri dan kanan. 

[mindmap]
Proyek Baru
  Riset
    Riset Pasar
    Kompetitor
  Desain
    Wireframe
    Mockup
  Development
    Backend
    Frontend
  Launch

10. Timeline (Kronologi)

Gunakan [timeline] di baris pertama. Setiap baris event ditulis sebagai tanggal : label [: sublabel]. Baris opsional title : ... (atau judul : ...) di atas event menambahkan judul. Kartu event bergantian otomatis di atas & bawah garis waktu. 

[timeline]
title : Sejarah MiniMermaid
2020 : Peluncuran Beta : 500 pengguna awal
2021 : Rilis 1.0 : 10K pengguna
2022 : Ekspansi Asia
2023 : Series A : $5M
2024 : Rilis 2.0
